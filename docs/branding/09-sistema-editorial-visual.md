# Sistema Editorial Visual do NSI

**Deriva de:** [`01-filosofia.md`](01-filosofia.md), [`07-tom-de-voz.md`](07-tom-de-voz.md), `docs/architecture/ADR-002-brand-foundation.md` (Seção 5 — Camada 2, Design System).
**Status:** Sprint 2 — Aprovado.
**Natureza:** Fonte única de verdade da identidade visual do NSI. Nenhuma cor, tipografia, grid, componente ou prompt é definido antes deste documento estar aprovado.

---

# 1. Objetivo

O Sistema Editorial Visual existe para garantir que **qualquer peça produzida pelo NSI seja imediatamente reconhecida como pertencente à marca** — antes mesmo de o logotipo aparecer, antes de qualquer texto ser lido.

Este documento não define como o NSI parece. Define **o que toda decisão de aparência precisa obedecer** antes de existir. Grid, tipografia, paleta, componentes e biblioteca de layouts (Camada 2 — Design System, conforme ADR-002, Seção 5) só serão desenhados depois que a filosofia registrada aqui estiver aprovada — a mesma disciplina que já regeu a Sprint 1: **arquitetura primeiro, implementação depois**.

Toda decisão visual futura do NSI — interna ou externa, em qualquer peça, canal ou formato — deve ser rastreável até um princípio registrado neste documento. Uma peça que não deriva de nenhum princípio aqui não é uma peça do NSI.

---

# 2. Filosofia Visual

A identidade visual do NSI traduz, em forma, a mesma postura que a [Filosofia](01-filosofia.md) já traduz em palavra: rigor em vez de impressão, evidência em vez de efeito.

### O que a identidade visual deve transmitir

| Traço | O que significa aplicado à forma |
|---|---|
| **Inteligência** | A peça parece pensada, não decorada. |
| **Precisão** | Nada está onde está por acaso; cada elemento tem uma razão de existir. |
| **Ciência** | A mesma objetividade que rege uma camada do Motor rege a composição visual. |
| **Tecnologia** | Sóbria e funcional — não futurista de forma decorativa, não "high-tech" de aparência. |
| **Organização** | Uma peça bem organizada não precisa de nada além de ordem para comunicar competência. |
| **Elegância** | Contenção, não ornamento. Elegância é o que sobra quando se retira o desnecessário. |
| **Sofisticação** | Sofisticação silenciosa — se precisa anunciar que é sofisticada, não é. |
| **Clareza** | Uma pessoa entende o que está vendo sem esforço. |
| **Discrição** | A marca não grita para ser notada; é notada por ser inconfundível. |

### O que a identidade visual nunca transmite

| Nunca | Por que é incompatível com o NSI |
|---|---|
| **Marketing agressivo** | O NSI não precisa convencer com volume — precisa ser entendido com precisão. |
| **Aparência de propaganda** | Propaganda promete; o NSI demonstra com evidência (mesma lógica de [`08-principios-editoriais.md`](08-principios-editoriais.md), Regra 1). |
| **Clickbait** | Contradiz diretamente o Princípio da Memorização: a peça deve deixar uma ideia certa, não gerar curiosidade vazia. |
| **Visual poluído** | Viola o Princípio do Respiro (Capítulo 3) e o Princípio da Singularidade já aplicado ao texto. |
| **Estética de "guru"** | O NSI não vende uma pessoa nem uma fórmula de sucesso — vende rigor sobre dado real. |
| **Excesso de elementos** | Cada elemento visual sem função é ruído — e o NSI já recusou tratar qualquer coisa como ruído descartável ([`01-filosofia.md`](01-filosofia.md), crença 3), inclusive na própria comunicação. |

# 3. Princípios Visuais

### Princípio do Respiro

Espaço vazio é informação, não desperdício. Uma peça sem espaço para respirar comunica ansiedade; uma peça com respiro comunica controle. Na dúvida entre adicionar um elemento e deixar espaço em branco, o espaço em branco vence.

### Princípio da Hierarquia

Nem tudo importa igualmente. Toda peça tem uma coisa que deve ser vista primeiro, uma que vem depois, e o resto que existe apenas como apoio. Uma peça onde tudo compete pela atenção não tem hierarquia — e sem hierarquia, não há clareza possível.

### Princípio da Clareza

Se uma peça exige explicação para ser entendida, ela falhou como peça visual. A forma existe para tornar o conteúdo mais rápido de entender, nunca para competir com ele.

### Princípio da Simplicidade

Simplicidade não é ausência de conteúdo — é ausência do que não é necessário. Um princípio simples de aplicar de forma consistente vale mais que um sistema visual complexo que ninguém consegue reproduzir igual duas vezes.

### Princípio da Ordem

Toda peça segue uma estrutura previsível. Ordem não é rigidez — é a razão pela qual quem vê uma peça do NSI sabe, sem pensar, onde procurar cada tipo de informação.

### Princípio da Continuidade

Uma peça nunca existe isolada. Cada peça nova é lida à luz de todas as anteriores — e deve se comportar como parte da mesma linguagem, não como uma reinvenção pontual para aquele contexto específico.

### Princípio da Consistência

A mesma decisão visual, aplicada ao mesmo tipo de conteúdo, produz sempre o mesmo resultado. Consistência é o que transforma uma peça isolada em identidade reconhecível — é a versão visual do Princípio 4 da ADR-002 (Versionamento como Governança): nada muda "de ouvido", tudo muda por decisão registrada.

### Princípio da Atemporalidade

Nenhuma escolha visual persegue uma tendência do momento. O critério de validação de qualquer decisão visual não é "está atual?", é "ainda vai fazer sentido em anos?" — aplicação direta do Princípio 6 da ADR-002 (Consistência de Longo Prazo).

# 4. Personalidade Visual

**Se o NSI fosse uma empresa física, como seria percebida?**

Como um instituto técnico, não como uma agência. Um lugar onde as paredes são claras, a iluminação é uniforme, os instrumentos estão organizados e nada está ali por decoração. Entra-se e a primeira impressão é de competência silenciosa — não porque alguém disse que é competente, mas porque tudo ali parece calibrado.

Não é um laboratório frio e impessoal, nem um escritório de consultoria cheio de gráficos coloridos tentando parecer dinâmico. É mais próximo de uma sala de instrumentos de precisão: cada objeto tem uma função, nenhum é maior do que precisa ser, e a ausência de excesso é, ela mesma, a assinatura do lugar.

Essa é a mesma personalidade que rege o Manifesto ([`02-manifesto.md`](02-manifesto.md)): rigor sem frieza, precisão sem exibição. O NSI seria a pessoa que fala pouco, mas quando fala, cada palavra pesa — porque sustentou o silêncio anterior com atenção real.

---

# 5. Sensações que toda peça deve transmitir

- **Confiança** — quem vê acredita que o que está sendo dito é sustentável.
- **Controle** — nada parece improvisado ou apressado.
- **Clareza** — a mensagem chega sem esforço de decodificação.
- **Competência técnica** — a peça parece ter sido feita por quem entende profundamente o assunto.
- **Calma** — a peça não pede uma reação imediata; ela espera ser lida com atenção.
- **Precisão** — cada elemento parece medido, não aproximado.
- **Seriedade** — o assunto tratado (a experiência real de um cliente) é tratado com o peso que merece.

---

# 6. Sensações proibidas

- **Urgência artificial** — nenhuma peça cria pressa fabricada para gerar reação.
- **Ansiedade** — nenhuma peça deixa quem vê com a sensação de estar perdendo algo.
- **Sensacionalismo** — nenhum resultado é dramatizado além do que a evidência sustenta (mesma regra de [`08-principios-editoriais.md`](08-principios-editoriais.md), Regra 4).
- **Informalidade excessiva** — o NSI é acessível, não íntimo demais para o contexto de decisão que ocupa.
- **Confusão** — nenhuma peça exige que quem vê pare para tentar entender o que está sendo comunicado.
- **Saturação** — nenhuma peça deixa a sensação de "elementos demais, tempo de menos".
- **Sensação de venda** — nenhuma peça parece existir para convencer em vez de demonstrar.

---

# 7. Reconhecimento de Marca

O NSI deve ser reconhecível **mesmo na ausência do logotipo** — este é o Princípio 7 da ADR-002 (Identidade Única), e este capítulo define como isso se constrói na prática visual.

Reconhecimento não vem de um símbolo. Vem da **repetição consistente dos Princípios Visuais** (Capítulo 3) até que a aplicação deles, sozinha, seja identificável. Uma marca é reconhecida pelo logotipo quando ainda não tem identidade própria; é reconhecida sem o logotipo quando sua linguagem visual amadureceu o suficiente para ser a própria assinatura.

Isso se constrói por três caminhos:

1. **Pela ausência tanto quanto pela presença.** O que o NSI decide não colocar em uma peça (Capítulo 2 — o que nunca transmitir) é tão parte da identidade quanto o que decide colocar.
2. **Pela coerência entre forma e voz.** Uma peça do NSI parece a peça de quem escreveu o [Tom de Voz](07-tom-de-voz.md) — preciso, direto, sóbrio. Forma e palavra nunca contam histórias diferentes.
3. **Pela repetição sem variação oportunista.** Cada peça nova aplica os mesmos princípios da anterior. Reconhecimento não sobrevive a reinvenção constante — é construído por anos de mesma decisão aplicada de novo (Princípio da Atemporalidade, Capítulo 3).

---

# 8. Critérios de Aprovação

Checklist que toda peça visual do NSI deve satisfazer antes de ser considerada aprovada. Uma resposta "não" em qualquer item é motivo de reprovação — a peça volta para revisão, não é publicada com ressalva.

- [ ] A peça seria reconhecida como NSI mesmo sem o logotipo visível?
- [ ] A peça transmite pelo menos as sensações obrigatórias do Capítulo 5, e nenhuma das proibidas do Capítulo 6?
- [ ] Cada elemento presente na peça tem uma função identificável — nenhum está ali "porque ficou bonito"?
- [ ] A peça respeita o Princípio do Respiro — existe espaço vazio suficiente para não comunicar ansiedade?
- [ ] Existe uma hierarquia clara: dá para dizer, sem hesitar, o que deve ser visto primeiro?
- [ ] A peça comunica uma única ideia central, coerente com o Princípio da Singularidade já aplicado ao texto ([`08-principios-editoriais.md`](08-principios-editoriais.md))?
- [ ] A peça seria reconhecível como NSI daqui a cinco anos, ou depende de uma tendência visual do momento (Princípio da Atemporalidade)?
- [ ] A peça poderia ser confundida com propaganda agressiva, clickbait ou estética de "guru"? Se sim, está automaticamente reprovada.
- [ ] A peça é consistente com peças anteriores do NSI, ou introduz uma variação sem justificativa registrada (Princípio da Consistência)?
- [ ] Cada decisão visual da peça pode ser rastreada até um princípio deste documento — e não até uma preferência pessoal de quem produziu?
